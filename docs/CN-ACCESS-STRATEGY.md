# 国内外访问方案（架构决策）

> 目标：国内用户正常访问且无证书警告
> 更新时间：2026-10-15 17:30

---

## 一、先纠正一个关键认知

**加阿里云服务器并不能解决证书问题。** 原因有两个：

### 1. 证书问题的根源是 SNI 被阻断

实测证据：

| 请求方式 | 服务器返回的证书 |
|---|---|
| 带 SNI（正常浏览器） | `CN=kanerg.com` ✅ |
| 不带 SNI（SNI 被丢弃） | `CN=*.github.io` ❌ |

浏览器在 TLS 握手中用SNI 扩展声明目标域名。国内网络链路会丢弃这个扩展，
服务器拿不到域名只能返回默认证书 → 浏览器报不匹配。

**挂 VPN 走境外链路时 SNI 完整送达，所以正常。**

### 2. 国内 CDN 同样需要备案

阿里云 CDN / 腾讯云 EdgeOne 的大陆节点**强制要求 ICP 备案**。
未备案只能使用香港或海外节点 —— 那样还不如现在的 Cloudflare。

---

## 二、现状实测

```
Cloudflare 节点命中：SIN（新加坡）
国内首字节时间：0.5 ~ 2.1 秒
境外首字节时间：0.24~ 0.32 秒
```

Cloudflare 在大陆的节点由合作方（京东云）运营，但**只对 Enterprise 客户 + 已备案域名开放**。
免费版的大陆流量会被甩到香港、日本，甚至美国西海岸。

**结论：Cloudflare 对国内不是加速，是绕路。**

## 三、三种方案对比

| 维度 | A 保持现状 | B 分双域名 | C 备案后双线|
|---|---|---|---|
| 成本 | 0 | 中| 低（备案免费，CDN 按量） |

| 用户体验 | 单域名 | **需记两个网址** | 单域名 |

### 方案 B 的致命问题

分 `kanerg.com`（海外）和 `cn.kanerg.com`（国内）看似可行，但：

- 国内节点依然要备案，绕不开
- 需要向用户分发两个网址，容易混淆
- 与你「任何用户访问同一网址」的诉求**直接冲突**

**不推荐。**

## 四、推荐路径

### 当前阶段（占位模板期）→ 保持方案 A

站点目前是占位模板，内容还会大改，访问量小。此时：

- **零成本、零维护**
- 国内访问慢 1~2 秒，但内容能正常显示
- 证书警告只影响部分国内直连用户

**建议先这样跑，等内容定稿后再投入备案。**

### 内容定稿后 → 启动方案 C

这是唯一的根治方案，且用户仍访问同一个网址。

#### 第1 步：ICP 备案（约 10~ 20 个工作日，费用约 0 元）

**入口**：阿里云备案系统 <https://beian.aliyun.com/>

**前置条件**（缺一不可）：

| 材料 | 要求 |
|---|---|
| 营业执照 | 公司副本彩色扫描件 |
| 法人身份证 | 正反面照片 |
| 网站负责人身份证 | 正反面照片 |
| 域名证书 | kanerg.com 的域名证书 |
| 真实性核验单 | 备案系统生成，需法人签字 |
| 负责人授权书 | 若法人非网站负责人 |

**注意**：
- 域名必须已在 registrar（万网/阿里云）完成实名认证
- 备案主体是**公司**，需要法人配合
- 期间网站需能正常访问（部分省份会核验）
- 备案通过前，国内 CDN 无法开通

#### 第 2 步：选择国内节点服务

备案通过后三选一：

| 服务 | 免费额度 | 特点 |
|---|---|---|
| **腾讯云 EdgeOne** | 有免费包 | 与腾讯云 CDN 同源，国内节点多 |
| 阿里云 CDN | 流量包 | 阿里系，与现有域名商一致 |
| 又拍云 + CDN | 5GB/月 | 流量小够用，接入简单 |

静态小站推荐**腾讯云 EdgeOne 免费版**或**又拍云**。

#### 第 3 步：部署静态资源到国内

```
GitHub Pages（源）→ 同步到国内对象存储（腾讯云 COS / 阿里云 OSS）
```

#### 第 4 步：智能解析分流

在 DNS 服务商配置「按线路解析」：

| 访问来源 | 解析目标 |
|---|---|
| 境内 | 国内 CDN 节点 |
| 境外 | Cloudflare 节点 |

**用户仍访问 `kanerg.com`，无需感知任何差异。**

## 五、备案期间的过渡方案

如果备案期间希望国内体验好一点，有两个低成本选择：

### 选项 1：引导 VPN 访问（零成本）

公司同事访问境外站点时挂代理，这在技术团队内部很容易推行。
适合：内部使用、访问量小。

### 选项 2：Cloudflare 改灰云（仅 DNS）

把橙色云改成灰色云，域名直接解析到 GitHub Pages IP：

- 大陆流量可能命中更近的 GitHub 节点
- **但会失去 HTTPS**（GitHub 证书问题未解决前不适用）

**当前不适用**，因为我们的 HTTPS 依赖 Cloudflare。

## 六、决策建议

| 时机 | 动作 |
|---|---|
| **现在** | 保持 Cloudflare，继续完善内容 |
| **内容定稿时** | 启动 ICP 备案（需公司法人配合） |
| **备案通过后** | 接入国内 CDN + 智能解析分流 |
| **国内访问量增长后** | 考虑完整迁移到国内（可选） |

**关键判断点：备案需要公司法人配合办理，请先确认公司是否愿意推进。**
