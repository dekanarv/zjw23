# VS Code 手动更新网站指南

> 你在 VS Code 里直接改代码，如何推送到线上。
> 更新时间：2026-10-16

---

## 一、完整操作流程

### 第 1 步：保存文件

```
Ctrl + S
```

**检查是否已保存**：编辑器标签页标题上如果有一个**圆点**（●），
说明文件有改动但没保存。保存后圆点会变成 × 或直接消失。

> 这一步很关键 —— 文件没保存就执行 git 命令，Git 拿到的是旧内容。

### 第 2 步：打开集成终端

```
Ctrl + `        （反引号，Esc 键下面那个）
```

或在菜单里：**终端 → 新建终端**

### 第 3 步：确认改了哪些文件

```bash
git status
```

输出示例：
```
On branch main
Your branch is up to date with 'origin/main'.

Changes not staged for commit:
  modified:   index.html
```

**这一步是保险** —— 确认你要提交的文件符合预期，
避免误提交临时文件（如 `.preview/`、截图等）。

### 第 4 步：暂存改动

```bash
git add -A
```

`-A` 表示把所有改动（新增、修改、删除）都暂存起来。

> 只改单个文件时也可以用 `git add index.html`

### 第 5 步：提交

```bash
git commit -m "简要说明你改了什么"
```

**提交信息建议写法**：

| 类型 | 示例 |
|---|---|
| 改文案 | `docs: 更新公司简介文案` |
| 改样式 | `style: 调整产品卡间距` |
| 加功能 | `feat: 新增产品详情页` |
| 改图片 | `assets: 替换首屏背景图` |
| 修问题 | `fix: 修复手机端导航错位` |

引号要用**英文半角引号**，中文内容放中间即可。

### 第 6 步：推送

```bash
git push
```

看到 `main -> main` 就成功了。

**约 1 分钟后刷新 <https://kanerg.com> 即可看到变化。**

## 二、一次复制粘贴版

如果改动不大，直接在终端里粘这一整段：

```bash
git add -A && git commit -m "更新首页内容" && git push
```

回车即可完成暂存、提交、推送三步。

## 三、VS Code 图形界面操作（不用记命令）

### 方式 A：源代码管理面板

1. 保存文件（Ctrl + S）
2. 点左侧边栏的**源代码管理**图标（一个分支形状的图标）
3. 在「更改」区域点击文件旁边的 **+** 号暂存
   - 或点文件右上角 `...` → **全部暂存**
4. 上方消息框输入提交说明，点 **✓ 提交**
5. 点面板右上角的 **···** → **推送**

### 方式 B：提交历史

左侧源代码管理面板 → **提交历史** → 找到之前的提交，
右键 → **推送**，可以一次性推送所有未推送的提交。

## 四、常见情况处理

### 1. 提示「nothing to commit」

说明文件内容跟上次提交完全一致，没有新改动。
如果你确实改了内容却报这个错，检查一下是不是**忘了保存**。

### 2. 提示「Updates were rejected」

远程有本地没有的新提交（多半是我或其他工具刚推的）。

```bash
git pull --no-rebase origin main
git push
```

先拉取合并，再推送。

### 3. 推送时卡住或超时

网络偶尔会不稳定，重试一次即可：

```bash
git push
```

### 4. 改错了想撤销（还没提交）

```bash
git checkout -- index.html
```

⚠️ 这会**丢弃所有未保存的改动**，无法恢复。执行前先确认。

### 5. 想撤销上一次提交（已提交未推送）

```bash
git reset --soft HEAD~1
```

改动会回到暂存区，可以重新编辑后再提交。

## 五、⚠️ 改 CSS/JS 后必须做这件事

改完样式或脚本后，记得把HTML 里的版本号更新：

```html
<link rel="stylesheet" href="assets/css/base.css?v=20261016b">
```

改成本次修改的标记（如 `?v=20261017`）。

**原因**：GitHub Pages 对 CSS/图片缓存 4 小时，但 HTML 只缓存 10 分钟。
不改版本号会出现「新版 HTML + 旧版 CSS」——页面显示错乱。

**快速定位**：在 VS Code 里搜索 `?v=`，所有需要改的地方会全部列出。

## 六、提交前建议的检查

推送后到线上确认一遍，比在本地发现问题更麻烦：

```bash
# 本地预览
python -m http.server 8130
# 浏览器打开 http://127.0.0.1:8130
```

确认没问题再 `git push`。

**改动了图片或 CSS 时，务必先本地看效果** ——
线上有缓存，本地预览才是修改后的真实样子。

## 七、一句话总结

```
Ctrl+S 保存 → Ctrl+` 开终端 → git add -A → git commit -m "说明" → git push → 等 1 分钟
```
